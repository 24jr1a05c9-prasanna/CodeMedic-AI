\# CodeMedic AI



\## Project Title

CodeMedic AI: Multi-Language Code Review and Error Detection System



\## Objective

To build a web application that checks source code for selected syntax errors and code-quality issues.



\## Technologies

\- Python

\- Streamlit

\- Python AST

\- Ruff

\- Java JDK (optional)

\- GCC or Clang (optional)

\- Node.js (optional)



\## Features

\- Select Python, Java, C, C++, or JavaScript

\- Analyze source code

\- Display syntax errors and warnings

\- Download a JSON report

\- Format Python code



\## How to Run

1\. Install Python.

2\. Install libraries using pip.

3\. Run the application using Streamlit.



\## Limitations

This is an educational static-analysis application. It does not execute submitted programs or detect every possible bug.
